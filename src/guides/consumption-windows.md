---
title: Wine consumption windows
summary: How long each style is good for, by region and type. These are the numbers behind "Drink now / soon / can wait".
order: 1
---

Years counted from the vintage, unless it says otherwise. Used by the app when you have not set your own window for a wine.

## Sherry

| Type | Window |
|---|---|
| Manzanilla, fino | 12-18 months from bottling |
| Cream, medium | 2-3 years |
| Amontillado | up to 5 years |
| VOS / VORS, palo cortado, oloroso, PX | no limit |

## Bordeaux

| Type | Window |
|---|---|
| Entry level, generic AC | 2-8 |
| Cru Bourgeois, second wines | 5-15 |
| Classified growths, left bank | 10-30+ |
| Classified growths, right bank | 10-25 |
| First growths | 15-40+ |
| Dry white | 5-20 (simple ones 1-2) |
| Sauternes | 10-40+ |

## Riesling

| Style | Window |
|---|---|
| Everyday | 1-3 |
| Kabinett | 2-8 |
| Spätlese | 5-15 |
| Dry single vineyard (GG) | 5-15+ |
| Auslese | 10-25+ |
| BA, TBA, Eiswein | 20-50+ |

See [Styles of Riesling](/guides/riesling-styles).

## Rioja

| Type | Window |
|---|---|
| Joven | 1-3 |
| Crianza | 3-8 |
| Reserva | 6-15 |
| Gran Reserva | 10-30+ |

Long-lived houses (López de Heredia, La Rioja Alta, Vega Sicilia...): start 2 years later, end 8 years later.

**White Rioja**

| Type | Window |
|---|---|
| Young, fresh | 1-4 |
| Oak, no designation | 2-8 |
| Reserva | 4-15 |
| Gran Reserva | 8-20 |

López de Heredia whites: 6-25.

## Cava

| Tier | Window |
|---|---|
| De Guarda | 1-1.5 |
| Guarda Superior Reserva | 1-2 |

## Champagne

| Type | Window |
|---|---|

| Vintage | 8-20+ |
| Prestige cuvée | 12-30+ |

## Port

|---|---|
