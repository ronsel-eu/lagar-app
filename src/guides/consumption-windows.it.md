title: Finestre di consumo dei vini

order: 1

Anni contati dall'annata, salvo diversa indicazione. L'app li usa quando non hai impostato una finestra tua per un vino.

## Sherry {#sherry}

| Tipo | Finestra |
|---|---|
| Manzanilla, fino | 12-18 mesi dall'imbottigliamento |
| Cream, medium | 2-3 anni |
| Amontillado | fino a 5 anni |
| VOS / VORS, palo cortado, oloroso, PX | senza limite |

## Bordeaux {#bordeaux}

| Tipo | Finestra |
|---|---|
| Entry level, AC generica | 2-8 |
| Cru Bourgeois, secondi vini | 5-15 |
| Grands crus classés, Riva sinistra | 10-30+ |
| Grands crus classés, Riva destra | 10-25 |
| Premiers crus | 15-40+ |
| Bianco secco | 5-20 (quelli semplici 1-2) |
| Sauternes | 10-40+ |

## Rioja {#rioja}

| Tipo | Finestra |
|---|---|
| Joven | 1-3 |
| Crianza | 3-8 |
| Reserva | 6-15 |
| Gran Reserva | 10-30+ |

Case di lunga evoluzione (López de Heredia, La Rioja Alta, Vega Sicilia...): inizio 2 anni più tardi, fine 8 anni più tardi.

Bianchi di López de Heredia: 6-25.
