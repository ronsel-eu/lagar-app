Années comptées à partir du millésime, sauf indication contraire. Utilisé par l'application lorsque vous n'avez pas fixé votre propre fenêtre pour un vin.

## Xérès {#sherry}

| Type | Fenêtre |
|---|---|
| Manzanilla, fino | 12-18 mois après la mise en bouteille |
| Cream, medium | 2-3 ans |
| Amontillado | jusqu'à 5 ans |
| VOS / VORS, palo cortado, oloroso, PX | aucune limite |

## Bordeaux {#bordeaux}

| Type | Fenêtre |
|---|---|
| Entrée de gamme, AC générique | 2-8 |
| Cru Bourgeois, seconds vins | 5-15 |
| Crus classés, rive gauche | 10-30+ |
| Crus classés, rive droite | 10-25 |
| Premiers crus classés | 15-40+ |
| Blanc sec | 5-20 (les simples 1-2) |
| Sauternes | 10-40+ |

## Riesling {#riesling}

| Style | Fenêtre |
|---|---|
| Courant | 1-3 |
| Kabinett | 2-8 |
| Spätlese | 5-15 |
| Sec, parcelle unique (GG) | 5-15+ |
| Auslese | 10-25+ |
| BA, TBA, Eiswein | 20-50+ |

Voir [Les styles de Riesling](/guides/riesling-styles).

## Rioja {#rioja}

| Type | Fenêtre |
|---|---|
| Joven | 1-3 |
| Crianza | 3-8 |
| Reserva | 6-15 |
| Gran Reserva | 10-30+ |

Maisons de longue garde (López de Heredia, La Rioja Alta, Vega Sicilia...) : début 2 ans plus tard, fin 8 ans plus tard.

| Élevé en fût, sans mention | 2-8 |

Blancs de López de Heredia : 6-25.
